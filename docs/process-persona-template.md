# Persona Entry Template

Use this template to add or update a persona entry in docs/octoacme-roles-and-personas.md

- Role name: (e.g., Release Manager)
- Role summary: 1–2 sentences describing ownership and scope
- Key responsibilities (bulleted):
  - ...
- Primary interactions (who they work with or hand off to):
  - ...
- Example scenarios / Ownership checkpoints:
  - ...
- Typical deliverables or artifacts:
  - ...
- Suggested acceptance criteria to mark role involvement as complete:
  - ...

Example:

- Role name: Release Manager
- Role summary: Coordinates release planning and execution to reduce risk and ensure smooth rollouts.
- Key responsibilities:
  - Maintain release checklist and scheduling
  - Coordinate cross-team sign-offs
- Primary interactions:
  - Project Manager, Developers, QA, Support
- Example scenarios:
  - Major release coordination, Hotfix rollout
